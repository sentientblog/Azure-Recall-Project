# Azure Recall — Demo Script

**Presenter:** Member B (or either team member)  
**Length:** About 60 seconds  
**Before starting:** Open the live Azure Recall app on the dashboard. Have one topic ready to study.

---

**[Show the dashboard]**

> “This is Azure Recall, our unofficial flashcard coach for AZ-900 revision.”

**[Choose any one of the six topics]**

> “On the dashboard, I choose one of six topics. Each card shows a question only, so I first try to answer from memory.”

**[Select Reveal Answer]**

> “When I reveal it, I get the answer, a short explanation of why it’s correct, and the Microsoft Learn source to verify it.”

**[Mark the card]**

> “If I missed it, I mark Review Again. If I understood it, I mark Got it. My progress is saved in the browser, so refreshing the page doesn’t erase it.”

**[Open Review Again mode from the dashboard]**

> “At the end, Review Again mode brings back only the cards I missed — so revision keeps focusing on my weak areas instead of starting over.”

**[Close]**

> “All 30 cards are original — five per topic — and every answer links to Microsoft Learn. Azure Recall is an unofficial study tool, not affiliated with Microsoft.”

---

**Fallback:** If the live app cannot be opened during the presentation, use the Product slide screenshots and narrate the same steps.
